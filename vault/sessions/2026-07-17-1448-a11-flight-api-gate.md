# Complete the A11 flight API gate

## What changed

- Added versioned organization-scoped flight-summary and track operations over
  the highest retained flight revision.
- Added exact-version telemetry reads with checksum, codec, capability, sample-
  count, and elapsed-bound verification before public projection.
- Added deterministic significant replay capped at 1,000 samples plus stable
  revision-bound full pages capped at 2,000, preserving nulls, extrema, and gap
  transitions truthfully.
- Kept storage identity and private source/parser provenance out of responses,
  errors, cache policy, and payload-free replay metrics while retaining current
  membership checks, forced RLS, and pooled-context clearing.
- Updated the generated OpenAPI/client snapshot, canonical product and
  architecture evidence, backlog, and hosted verify gate; pushed implementation
  commit `2b0959d` to `origin/main`.

## Why

A12 now has one truthful first-party API surface for opening the A10 flight and
rendering its 2D route without bypassing tenancy or exposing private persistence
details. The same boundary supports deterministic verification of the full
retained telemetry without allowing an unbounded response.
