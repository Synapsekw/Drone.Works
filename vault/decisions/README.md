# Vault decisions and gotchas

This folder is not the Drone.Works architecture decision log. Product and technical decisions remain canonical in [docs/product/DECISIONS.md](../../docs/product/DECISIONS.md).

Use this folder only for:

- decisions about the project-memory workflow itself;
- non-product tooling traps that would otherwise be repeatedly rediscovered;
- short links back to the canonical decision when a session needs extra navigation.

Use `vault/templates/vault-decision.md` and keep the scope explicit.
