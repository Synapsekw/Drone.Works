# Security policy

Drone.Works handles sensitive operational information, including flight locations, telemetry, fleet identifiers, and pilot records. Please report suspected vulnerabilities privately.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting or security-advisory feature for this repository when available. Do not open a public issue containing exploit details, credentials, customer data, flight logs, or precise operational locations.

Include, where possible:

- the affected component or behavior;
- reproduction steps or a minimal proof of concept;
- the potential impact;
- any suggested mitigation;
- a safe way to contact you for follow-up.

Do not access, modify, download, or retain data that does not belong to you. Stop testing once a vulnerability has been demonstrated sufficiently to report it.

## Scope during the pre-release stage

The project has not published a production release. Security reports about repository content, exposed secrets, dependency configuration, or deployed preview environments are still welcome. Supported release versions and response targets will be added before public production use.
