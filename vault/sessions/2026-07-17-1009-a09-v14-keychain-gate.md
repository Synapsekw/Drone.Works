  enablement interlocks, and the narrow public DJI Fly/TXT v14 matrix.

parser network access or distributing plaintext key material. The narrow v14
path closes that walking-skeleton blocker while preserving organization
isolation, explicit consent, failure clarity, deletion, and parser containment.
